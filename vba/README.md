# Excel VBA macros

Coming soon. Each macro will ship with:

- the `.bas` module (plain text, so you can read every line before running it)
- a short "what it does" note with before/after screenshots
- install steps: **Alt + F11 → File → Import File… → select the `.bas` → run with Alt + F8**

> Macros are shared as `.bas` text files rather than `.xlsm` workbooks, so nothing runs automatically when you open a file.
