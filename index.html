Tool 01 · HTML

PDF Suite

Fifteen PDF tools in a single file. Every page is processed inside your browser, so client documents never leave your computer.

  • Merge with annexure dividers
  • Split, extract and reorder pages
  • AES-256 password protection
  • Redact PAN, Aadhaar and GSTIN
  • Compress for e-mail and portals
  • Bates and section page numbers
  • Watermarks, stamps and signatures
  • PDF ↔ images, PDF → Word

Tool 02 · Excel VBA

Encrypt / Decrypt Data

Select cells, run one macro, and client names, PANs and other text turn into unreadable symbols. Run the second macro to bring them back.

  • Masks every letter in the selection
  • Restores the text exactly
  • Leaves numbers and dates alone
  • Formulas are never touched
  • Works on any selection or sheet
  • Plain .bas file, easy to review

Masking hides text from casual view, for example in screenshots or demo files. It is not password security: anyone with this macro can reverse it.
